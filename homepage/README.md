# 홈페이지 (랜딩 페이지 & 로그인) 수정 안내서

이 폴더(`homepage/`)는 Mystair의 메인 랜딩 페이지(소개 화면 및 로그인 화면)를 구성하는 파일들을 친구분께 전달하기 위해 모아둔 폴더입니다.

---

## 📁 주요 파일 설명

1. **`Dashboard.tsx` (가장 핵심 - 랜딩 페이지 화면 및 아래 내용)**
   - "내 손으로 만들어가는 당신만의 멋진 계단" 타이틀
   - "무료로 시작하기" 버튼
   - 아래로 스크롤했을 때 나오는 모든 기능 소개 카드, 핵심 특징, 통계 수치, FAQ 아코디언 등 랜딩 페이지의 모든 본문 내용이 들어있습니다.

2. **`App.tsx` (상단 헤더 & 전체 프레임 레이아웃)**
   - 상단 네비게이션 바 (Mystair 로고, 마이스터고 지도 링크, 만든 사람들 링크, 언어 변경(한국어/EN), 로그인 버튼)
   - 3D Spline 배경과 별빛 배경(Starfield)을 감싸는 전체 페이지 구조입니다.

3. **`SplineBackground.tsx`**
   - 우측의 3D 인터랙티브 회전 계단 포털 그래픽을 불러오는 파일입니다.

4. **`Starfield.tsx`**
   - 은하수/별빛이 은은하게 반짝이는 캔버스 배경 효과 파일입니다.

5. **`Login.tsx`**
   - "무료로 시작하기" 또는 상단 "로그인" 버튼 클릭 시 열리는 로그인 모달/화면입니다.

6. **`LanguageContext.tsx`**
   - 한국어/영어/중국어 다국어 번역 텍스트 사전입니다.

7. **`PrivacyPolicyModal.tsx`**
   - 개인정보처리방침 모달입니다.

---

## 💡 수정 후 반영 방법
친구분이 이 폴더 안의 파일(주로 `Dashboard.tsx`나 `App.tsx`)을 수정한 뒤 코드를 전달해주시면,
채팅창에 **"이 코드로 homepage 반영해줘"**라고 붙여넣어 주시면 즉시 본 프로젝트에 자동 동기화 적용됩니다!
