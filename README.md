# 📈 MyStair (마이스테어)
> **하루의 기록이 스펙이 되는 마이스터고 맞춤형 커리어 빌더 & 나만의 전용 AI 컨설턴트**

MyStair는 마이스터고 학생들이 3년간 쌓은 실습·대회·자격증 기록의 의미를 구체화하고, 서비스 내 모든 기능과 유기적으로 상호작용하는 '전용 AI'를 통해 팩트 기반 자소서 추출부터 실전 압박 모의 면접까지 지원하는 과정 중심 커리어 빌더입니다.

---

## 💡 기획 배경 및 문제 정의

현직 마이스터고 취업 지도 교사 인터뷰 및 학생 필드 리서치를 통해 파악한 3가지 핵심 페인포인트는 다음과 같습니다.

1. **경험에 대한 의미 부여 및 구체화 부재**  
   단순히 과거 실습을 잊어버리는 것을 넘어, 본인이 겪은 실습이나 프로젝트에서 어떤 역량을 발휘했고 어떤 트러블슈팅을 해냈는지 스스로 의미를 부여(메타인지)하지 못해 기록으로 남기지 못합니다.
2. **범용 AI 의존으로 인한 실무 면접 붕괴**  
   ChatGPT 등 범용 AI에 의존하여 겉만 번지르르한 허구의 자소서를 작성하지만, 정작 본인의 경험이 머릿속에 내재화되지 않아 실무진 압박 면접에서 방어에 실패합니다.
3. **정량 스펙과 목표 기업 간의 갭(Gap) 인지 부족**  
   자신의 전공 역량과 자격증 수준이 목표 기업의 채용 기준에 얼마나 부합하는지 객관적으로 파악하기 어렵고, 부족한 역량을 채울 수 있는 차별화된 활동(대회, 외부 교육 등)을 찾기 어렵습니다.

## ✨ 주요 기능 (MVP 핵심 행동)

* **📝 [기록 & 심화] AI 세부 질문 기반 경험 다이어리**  
  학생이 오늘 겪은 실습/대회 내용을 한 줄로 가볍게 입력하면, AI가 "어떤 에러가 발생했는지", "팀에서 본인의 역할은 무엇이었는지" 실시간 꼬리 질문을 던져 경험의 의미를 구체화하고 다이어리로 자동 정리합니다.
* **🎯 [추출] 팩트 기반 초개인화 STAR 자소서 가이드**  
  누적된 다이어리 DB에서 지원 문항 의도와 가장 완벽하게 부합하는 실제 에피소드를 매칭하여 논리적인 S(상황)-T(과제)-A(행동)-R(결과) 구조로 자소서 뼈대를 세워줍니다.
* **🎙️ [내재화] 실전 대비 AI 압박 모의 면접**  
  생성된 자소서를 기반으로 AI가 면접관 페르소나를 장착하여 날카로운 꼬리 질문을 던집니다. 학생은 실시간 질의응답을 거치며 자신의 경험을 완벽히 머릿속에 정리하고 면접 방어력을 기릅니다.

## 🔄 서비스 작동 원리 (AI Pipeline)

```text
[학생의 한 줄 실습 기록] 
         │
         ▼
[AI 세부 꼬리 질문 (Streaming)] ──> "어떤 오류가 발생했고, 어떻게 해결했나요?"
         │
         ▼
[역량 태깅 및 경험 다이어리 적재 (Function Calling)] ──> PostgreSQL 암호화 저장
         │
         ▼
[자소서 문항 매칭 (RAG 변형)] ──> 3년 치 DB 중 문항 의도에 맞는 팩트 에피소드 추출
         │
         ▼
[STAR 자소서 개요 생성] ──> 논리적 S-T-A-R 뼈대 도출
         │
         ▼
[AI 실전 압박 모의 면접 (In-Context)] ──> 작성된 자소서 기반 면접관 질문 & 피드백
🏗 시스템 아키텍처
[ CLIENT ]
    │  Next.js 14 / React (Vercel 배포)
    │  - Spline 기반 3D 인터랙티브 UI
    │  - 다이어리 입력 및 실시간 스트리밍 대화형 UI
    │  - AI 모의 면접 시뮬레이션 인터페이스
    ▼
[ SERVER (API Layer) ]
    │  Next.js Route Handlers / Server Actions
    │  - 개인 식별 정보 비식별화(가명화) 전처리
    │  - 세부 질문 및 면접관 페르소나 System Instruction 주입
    ├───────────────────────────────┐
    ▼                               ▼
[ EXTERNAL AI PIPELINE ]      [ DATABASE ]
  Google AI Studio              Render (PostgreSQL)
  - Gemini 3.5 Flash-Lite        - diaries (실습 기록 및 AI 꼬리 질문 응답)
    (실시간 꼬리 질문 & 모의 면접)  - interview_logs (모의 면접 Q&A 데이터)
  - Gemini 3.1 Pro / 2.5 Flash   - users / credentials (암호화 계정 정보)
    (STAR 자소서 변형 RAG 추출)
🤖 AI 핵심 기술 및 적용 내역
대화형 꼬리 질문 파이프라인: 단발성 입력을 방지하기 위해 사용자 발화의 구체성 여부를 평가하고, 육하원칙에 입각한 직무 심화 질문을 실시간 스트리밍(Streaming API)으로 유도합니다.

RAG (검색 증강 생성) 변형 기법: 사용자의 누적 다이어리 데이터에서 기업 자소서 문항과 부합하는 에피소드만을 벡터 검색하여, AI의 환각(Hallucination) 현상을 차단하고 100% 본인의 팩트만 반영합니다.

Function Calling 기반 DB 트랜잭션: 대화 중 확정된 실습 경험과 역량 태그를 AI가 스스로 판단하여 백엔드 DB 스키마 규격에 맞추어 적재합니다.

면접관 페르소나 프롬프트 엔지니어링: 완성된 자소서를 기반으로 AI에게 엄격한 마이스터고 기술 면접관 역할을 부여하여 지원자의 논리적 허점을 찌르는 압박 질문을 생성합니다.
